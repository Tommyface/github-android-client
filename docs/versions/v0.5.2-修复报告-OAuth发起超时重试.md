# v0.5.2 修复报告：OAuth 发起授权超时重试与文案中文化

**日期**：2026-11-24
**版本**：versionCode 7 / versionName 0.5.2（debug，签名 SHA-256 与前六版连续不变，可覆盖安装）
**前置版本**：v0.5.1（versionCode 6）

---

## 一、问题现象

用户点击「GitHub 账号登录」后报错：

```
发起授权失败：[-11] Socket timeout has expired
[url=https://github.com/login/device/code, socket_timeout=unknown] ms
```

## 二、根因分析

| # | 层级 | 问题 |
|---|------|------|
| 1 | 环境 | Device Flow 端点在 `github.com`（非 `api.github.com`），国内直连间歇可达；30 秒 socket 超时后连接失败。**此类授权端点无法走 ghfast.top / jsdelivr 等文件镜像加速**（涉及授权凭据安全 + 镜像仅代理文件类资源）。 |
| 2 | 代码 | 发起阶段 `OAuthDeviceFlowRepositoryImpl.startDeviceFlow()` 为**单发请求、零重试**——一次超时即中止（轮询阶段反而已有「连续 3 次错误才中止」的容错）。 |
| 3 | 代码 | 异常原文（英文）直接透传到 UI，用户无从判断该做什么。 |

注：`socket_timeout=unknown` 是 Ktor/OkHttp 引擎抛出 `SocketTimeoutException` 时的异常信息格式，超时配置（connect 15s / socket 30s）实际已生效，非配置丢失。

## 三、修复内容

### 1. 发起阶段自动重试（`OAuthDeviceFlowRepositoryImpl`）

- 最大尝试 **3 次**（首用 + 2 次重试），退避间隔 2s、4s；`retryDelayMillis` 构造注入（测试传 0 加速）。
- **仅传输层异常（code = -1）重试**；HTTP 状态码错误（如 503）与响应解析失败立即中止，避免无意义等待。

### 2. API 层错误码语义化（`GitHubOAuthApi`）

| 约定码 | 含义 | 上层行为 |
|--------|------|----------|
| `-1` | 网络传输异常（timeout / reset / DNS） | 重试 |
| `-2` | 响应解析失败 | 不重试 |
| `> 0` | HTTP 状态码 | 不重试 |

### 3. 错误文案中文化（`AuthViewModel.friendlyDeviceFlowError`，顶层函数便于单测）

| 触发关键字 | 新文案 |
|-----------|--------|
| `timeout` | 网络连接超时：直连 github.com 无响应。请切换网络（WiFi ↔ 流量）、开启代理，或稍后重试（github.com 在国内间歇可达） |
| `unable to resolve` / `unknownhost` | 域名解析失败：当前网络无法访问 github.com。请切换网络或开启代理后重试 |
| `reset` / `failed to connect` / `unexpected end` / `broken pipe` | 网络连接中断：请求被重置。请切换网络（WiFi ↔ 流量）或开启代理后重试 |
| 其他 | 原文透传 |

覆盖两处调用：发起失败（`发起授权失败：…`）与轮询中止（`网络异常，授权已中止：…`）。

### 4. 版本 bump

`AndroidApplicationConventionPlugin.kt`：versionCode 6 → **7**，versionName 0.5.1 → **0.5.2**（全仓唯一硬编码处）。

## 六、用户侧立即可试方案（无需等新版本）

1. **多点一次「登录」**：github.com 在国内间歇可达，重试常能通过（新版本将自动重试 3 次）。
2. **切换网络**：WiFi ↔ 手机流量。
3. **开启代理**：App 走系统代理——VPN 类全局代理或对 `github.com` 放行的分流规则均可生效。

## 七、遗留说明

- Device Flow 授权端点属凭据安全敏感面，**不引入第三方代理镜像**；网络可达性依赖用户侧网络质量，重试 + 文案指引已是客户端层最优解。
- 若持续超时且无代理可用，可改用 **PAT 登录**（同一登录页的备用入口）。
