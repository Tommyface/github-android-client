# 威胁模型（STRIDE + 资产清单）

> 对应《GHHub 最优修改报告》§6.1。本文件是「安全超越清单」与「写能力安全 Gate」的依据，
> 每次引入新权限、新网络出口、新写操作时必须复核。

## 一、资产清单

| 资产 | 敏感度 | 关键性 | 存放位置 |
|---|---|---|---|
| OAuth Token / PAT | 极高 | 高 | AndroidKeyStore 加密的 EncryptedSharedPreferences |
| 仓库写权限 | 高 | 高 | 同上（凭据派生） |
| 下载产物完整性（APK） | 高 | 高 | 私有下载目录 + 签名指纹钉子 |
| 用户凭据类型与 scope | 中 | 高 | 同上 |
| 本地缓存（仓库/Issue/日志） | 中 | 中 | Room / DataStore |
| 操作审计记录 | 中 | 中 | 本地加密存储（30 天） |
| 诊断日志 | 中 | 中 | 本地文件（导出前强制脱敏） |
| 应用本体 | — | 高 | 发布签名 + 官方渠道 + 指纹公示 |

## 二、STRIDE 威胁与对策

| 类别 | 威胁场景 | 对策 | 落点 |
|---|---|---|---|
| **Spoofing** | 伪造令牌 / 伪造更新包 / 伪造仓库身份 | 令牌仅存加密域且不入日志；更新走「版本号 + SHA-256 + 签名证书指纹」三信号；域名出口白名单 | `core/data`、`feature/download` |
| **Tampering** | 篡改 APK / 篡改源码 / 篡改配置 | 产物 SHA-256 + 签名指纹比对，不一致即删除文件并失败；CI 三处版本一致校验；gradle 依赖锁定校验 | `release.yml`、`security.yml` |
| **Repudiation** | 写操作无追溯 | 写操作统一经 `MutationExecutor` 并落审计日志（加密、30 天、可导出） | `core/mutation`、`core/audit` |
| **Information Disclosure** | 令牌进日志 / 备份 / 截图 | 日志脱敏器强制；`allowBackup=false` + dataExtractionRules 排除；诊断码只展示前 16 位摘要；Token 不进领域模型 | `platform/diagnostics` |
| **Denial of Service** | 无限重试打爆配额 | 指数退避 + 抖动；限流熔断；写操作幂等键 + 可重放但有上限 | `core/data/network` |
| **Elevation of Privilege** | 越权操作 / 二次打包夹带偷 Token | scope 最小化 + 权限矩阵可见；破坏性操作二次确认；五环链降级告警 + 官方指纹公示 | `feature/auth`、`platform/guard` |

## 三、信任边界

```
┌──────────────────────────────────────────────────┐
│ UI 层（presentation）                             │  ← 永不可见令牌明文
├──────────────────────────────────────────────────┤
│ 领域层（domain，纯 Kotlin）                        │  ← 无 Android 依赖
├──────────────────────────────────────────────────┤
│ 数据层（data）        │  平台层（platform）       │  ← 凭证只在此二处可见
├──────────────────────────────────────────────────┤
│ 外部：api.github.com │ 官方源直连优先            │  ← 镜像不得承载凭据流量
│      镜像 / 代理（仅产物下载，无凭据）             │
└──────────────────────────────────────────────────┘
```

**红线**：
1. 任何网络出口携带 `Authorization` 时，目标必须是 GitHub 官方域名；
   跳转到对象存储的那一跳必须**摘除** Authorization。
2. 镜像 / 代理只用于**产物下载**（Release 资产、raw 文件），不得用于 API 与凭据流量。
3. 在线翻译等外发正文的能力默认关闭，开启时必须明示。

## 四、权限预算

| 权限 | 必要性 | 可否按需 |
|---|---|---|
| INTERNET | 必需 | 否 |
| ACCESS_NETWORK_STATE | 必需 | 否 |
| POST_NOTIFICATIONS | 通知中心 / 下载进度 | 是（拒绝不影响主流程） |
| FOREGROUND_SERVICE + DATA_SYNC | 后台下载 | 是（关闭后下载不可后台进行） |
| REQUEST_INSTALL_PACKAGES | 安装 APK | 是（关闭后仅提示用户手动安装） |
| CAMERA（扫码） | TOTP 扫码 | 是（关闭后 TOTP 仍可手动输入密钥） |

目标：**权限总数 ≤ 6**，每项按需申请，关闭功能后权限可被系统回收。

## 五、写操作安全 Gate（不通过不合并）

1. 写操作统一走 `MutationExecutor`：幂等键 + 乐观 UI + 失败回滚 + 部分成功处理 + 可重放。
2. 破坏性操作（删库 / 改可见性 / 归档）：二次确认 + 明确展示方向与后果 + 操作日志。
3. scope 按需申请（最小权限），设置页展示「当前凭据能做什么」。
4. Token 一键吊销 + 一键清空全部本地数据。
5. 写操作日志本地加密保存 30 天，可导出「操作审计报告」。
