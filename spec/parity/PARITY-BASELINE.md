## 三、不追清单

| 项 | 原因 |
|---|---|
| 云端一键打包 APK | 需长期跟随 Actions 模板与 Secrets API 变更；与「发现→评估→下载」定位冲突。降级为可选开关（P3） |
| 局域网同步 / 配对 | 网络暴露面与「零不可控依赖」冲突，默认不做 |
| 限速下载通道 | 以可用性为杠杆的软性施压，拒绝 |
| 自研 JS 二维码解码 | 稳定性差，改用 CameraX + ML Kit |
| WebView 承载全部 UI | 攻击面 / 稳定性 / 可访问性 / 性能全面劣于 Compose |
| 默认在线翻译 | 正文外发第三方，违背隐私承诺；改默认离线、在线需显式开启 |

## 四、基线升级规则

- 每 90 天允许手动升一次；升级走独立 PR（评审增量），**不自动跟随**。
- 升级时必须重跑一次能力探测清单，并把新增/失效条目写入本文件。
