## 三、阅读约定

- 报告中的「实测 / 实测结论」是**当时**的端点探测结果，可能已失效；
  重新实现某能力前须按《GHHub 最优修改报告》的纪律**重新探测**。
- 「诚实降级 / 不做」的条目是**决策记录**，不是待办；除非有新证据推翻，不要重新捡起。
